项目概述

TreeGraph Studio 是一款基于C++和Qt5开发的图算法可视化教学系统，专为数据结构或离散数学等涉及图相关的课程设计。它提供了直观的图形界面，帮助用户创建、编辑和可视化各种图结构（树、有向图、无向图），并实时演示经典图算法的执行过程。

系统采用模板化设计，支持高度可扩展的图算法实现，内置了BFS、DFS、Dijkstra最短路径和Kruskal最小生成树等核心算法，并可扩展其他算法。通过动画、颜色编码和逐步执行功能，将抽象的图论概念转化为直观的视觉体验。

本系统也内置了教学模块，可以选择使用文件内置的教学文档、教学视频以及图案例等，便于初学者快速了解并进行实践。我们的学习系统也支持自行导入学习文档（.md, .txt）、音视频（.wmv [由于文件特性.mp4需要另外安装解码器支持]）、图（.graph）。

🚀 快速开始

第一步：启动程序

  1. ./TreeGraphStudio

第二步：创建图结构

  1. 选择图类型：在左侧面板选择”无向”或”有向”
  2. 进入编辑模式：点击”添加节点”或”添加边”
  3. 构建图：
    • 添加节点：在画布空白处点击
    • 添加边：依次点击两个节点，输入权重

第三步：运行动画

  1. 选择算法：在右侧面板选择BFS/DFS/最短路径/最小生成树
  2. 设置起点：点击选择起始节点（最短路径需额外选择终点）
  3. 点击运行：观察算法执行过程
  4. 控制动画：使用暂停/继续/上一步/下一步按钮

第四步：保存成果

  • 点击菜单栏”文件”→”保存”，导出.graph文件

📖 详细使用指南

图类型选择

类型 特点 适用算法
无向图 边无方向，双向连接 BFS, DFS, Dijkstra, Kruskal
有向图 边有方向，带箭头 BFS, DFS, Dijkstra
树 无环，每个节点至多一个父节点 BFS, DFS

编辑模式详解

1. 选择模式（默认）

  • 选择节点：单击节点查看信息，作为算法起点
  • 拖拽移动：按住节点拖动改变位置
  • 右键菜单：
    • 重命名：修改节点标签
    • 删除节点：移除节点及其关联边
  • 边操作：右键边可编辑权重或删除

2. 添加节点模式

  • 创建节点：在画布空白处点击
  • 自动命名：按顺序生成”Node0”, “Node1”等名称
  • 坐标显示：开启后可看到精确坐标

3. 添加边模式

  • 选择起点：点击第一个节点（变为绿色）
  • 选择终点：点击第二个不同节点
  • 输入权重：弹出对话框输入正整数权重
  • 取消操作：再次点击起点取消选择

算法使用指南

BFS（广度优先遍历）

  • 特点：逐层访问节点，使用队列
  • 起点：任意节点
  • 可视化：黄色节点为已访问，蓝色悬停

DFS（深度优先遍历）

  • 特点：深度优先，使用栈
  • 起点：任意节点
  • 可视化：遍历顺序实时显示

Dijkstra最短路径

  • 特点：计算单源最短路径（有向/无向）
  • 起点与终点：需分别指定
  • 可视化：高亮最短路径，显示总距离
  • 注意：权重必须为正数

Kruskal最小生成树

  • 特点：贪心地选择权值最小的边
  • 无需起点：自动处理全图
  • 可视化：
    • 黄色边：已选中的MST边
    • 红色虚线：被 rejecting 的边（会形成环）

🎯 核心模块

1. GraphCanvas（图画布）

定位：核心交互组件
功能：

  • 处理所有鼠标事件和绘图逻辑
  • 管理节点/边的UI元素（QGraphicsItem）
  • 算法动画的渲染和状态更新
  • 模板化支持多种图类型

关键设计：

  • 使用void*指针存储模板化图对象，实现运行时多态
  • AlgorithmWrapper结构体统一不同算法的接口
  • 步骤历史机制支持前进/后退

2. Graph/Tree（数据结构）

特点：

  • 完全模板化：Graph<NodeData, EdgeWeight, Directed>
  • 智能指针管理内存：unique_ptr<NodeType>和unique_ptr<EdgeType>
  • 高效的邻接表存储：unordered_map<int, vector<int>>
  • 树结构特有：环检测、单父节点校验

3. 算法模块

统一接口：

  1. // 所有算法支持逐步执行
  2. void initialize(int startNode);
  3. bool step();  // 执行一步，返回是否还有更多步骤
  4. void runAll(); // 运行全部

回调机制：使用std::function实现事件驱动的可视化更新

4. 学习系统集成

松散耦合：通过信号/槽机制与主窗口通信
静默加载：loadGraphQuietly避免错误弹窗干扰用户体验
资源管理：自动创建learning resources目录结构

🧮 支持的算法

遍历算法

算法 时间复杂度 空间复杂度 适用图类型 特点
BFS O(V+E) O(V) 有向/无向/树 队列实现，分层遍历
DFS O(V+E) O(V) 有向/无向/树 栈实现，深度优先

最短路径（Dijkstra）

  • 时间复杂度：O(E log V)（优先队列优化）
  • 限制：仅支持正权边
  • 输出：起点到所有节点的最短距离，以及目标路径

最小生成树（Kruskal）

  • 时间复杂度：O(E log E)（排序为主）
  • 适用：仅无向图/树
  • 输出：MST边的集合和总权重
  • 拒边可视化：红色虚线显示被排除的边

⚠️ 注意事项

技术要求

  1. C++模板复杂性：核心模块重度使用模板，编译时间可能较长
  2. Qt依赖：必须完整安装Multimedia模块，否则视频功能不可用
  3. 内存管理：使用智能指针，但算法包装器需手动delete防止内存泄漏

使用限制

  1. 最短路径权重：Dijkstra算法要求所有边权为正数，负数会导致错误结果
  2. Kruskal适用范围：有向图无法使用最小生成树功能
  3. 树结构约束：每个节点只能有一个父节点，添加边时会自动检测环
  4. 节点命名：节点名称必须唯一，大小写敏感

视频播放

  1. Windows推荐格式：WMV/AVI（无需额外解码器）
  2. MP4/MKV支持：必须安装K-Lite Codec Pack Basic
  3. 路径问题：避免使用中文或特殊字符路径，可能导致加载失败

❓ 常见问题

Q1: 编译时出现”Qt5 Multimedia not found”错误
A: 确保Qt安装时勾选了Multimedia模块，并正确设置CMAKE_PREFIX_PATH

Q2: 视频无法播放，提示”格式不支持”
A: Windows用户请安装K-Lite Codec Pack Basic，Linux用户安装ffmpeg

Q3: 加载.graph文件失败
A: 检查文件类型是否与当前图类型匹配（有向/无向），可尝试切换图类型后重新加载

Q4: Kruskal算法在有向图上无法使用
A: 这是设计限制，最小生成树仅定义于无向图。请先切换为无向图模式

Q5: 节点名称无法重复
A: 系统使用名称作为唯一标识符，重复名称会导致映射冲突。请使用唯一名称

Q6: 如何添加自定义算法？
A: 在algorithms/目录下创建新类，继承统一接口，在GraphCanvas::startAlgorithm中添加分支
